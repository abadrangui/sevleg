# Raw material index

This folder keeps the **raw** research behind the report, so agents can check a quote or a number without searching the web again. The cleaned, cited summary is `reports/Mongolian first haircut ceremony.md`. Start with `AGENTS.md` at the repo root.

All files were collected on 2026-10-11, except where noted.

## facebook/

| File | Content |
|---|---|
| `facebook-posts.md` | Notes on posts P1–P25 from the public group "Сэвлэг үргээх ёсон" (https://www.facebook.com/groups/288381221961390/, ~101k members). Each post has its URL, date and reaction count. They cover real menus, guest numbers, prices in ₮, vendors, return gifts, what to do with the hair, and the lama-vs-big-party debate. Short English notes, with Mongolian quotes. |
| `facebook-blessings.md` | Blessing (ерөөл) and praise (магтаал) texts found on Facebook, with source links. It includes regional rules on who cuts first and a list of lunar days. |

These notes link to posts by private people. The user chose to keep them in this public repo.

## blessing-texts/

Clean Mongolian verse, one block per file. The tickets in `print/yerool-tickets.html` are built from these.

| Code | Content |
|---|---|
| `T1` | Full traditional blessing "Хүүхдийн үс үргээхэд хэлэх ерөөл", version A (as published by Тусгал.мн): "Эрхэм дүү … –ний / Энхрий бяцхан хүүгийхээ…" |
| `T2` | Longer version B, which opens "Эрхэм хайрт танайх болвол / Түмэн өлзий бүрдсэн…" |
| `U1` | The reciter's (ерөөлч) opening: "Энхрий бяцхан хүүгийнхээ / Онгон хонгор даахийг нь…" |
| `U2` | Scissors verse: "Ган цагаан хайлш / … Алтай хайчны амыг нээж…" |
| `U3` | Temple verse: right temple, then left temple, then crown. "Баруун талын шанаанаас…" |
| `V1` | Father's-virtues verse: "Номд мэргэн / Нойронд сэргэг…" |
| `V2` | Long-life verse: "Оройн сэв нь / Онгон буурал болж…" |
| `DM` | "Бэлэг дэмбэрлийн үгс": short "…яв" wishes for guests |
| `CM` | Drink (идээ) blessing from the long Creative Mongolia version. It mentions архи, so the ceremony does not use it as is. |

These are copies of the source texts. A few spellings in the sources differ from the fixed ticket text (for example "Буурашгуй" in the source and "Бууршгүй" on the ticket). Treat the ticket HTML as the corrected version.
